# The Great Galactic Library

Not a dump. A **card catalog**.

Every bench, node, experiment, and body gets one card. The card says what it is, where it lives, what would kill it, and what it is allowed to touch.

No control but self-control. The library does not decide. It remembers where the decisions live.

## How to add a card

Copy `cards/_TEMPLATE.md`. Fill every field. If you cannot write a falsifier, the thing is not a card yet. It is a mood.

```bash
python catalog.py
```

Prints the shelf. That is the whole UI until someone earns a prettier one.
